# E2 尺度无关 DIC 特征聚类：源码复核

复核日期：2026-11-11。范围：本目录 4 个 Python 脚本、README、现有输出及直接调用的 E1 / Ren2026 / methodScripts 函数。已核对语法、样本规模，并从保存的标签独立复算两组 DIC 的 ARI 和切换时刻；未从原始点场重跑全流程，未核验原论文的物理判据。

## 1. 本轮完成了什么

**本目录完成了 HS-2 单试样的“特征构造 → 单模态无监督聚类 → 与载荷阶段事后对齐评价”，为后续多源融合筛选特征。** AE、DIC 虽按同一时间轴汇总，但分别聚类；尚无联合表征、多模态融合、自监督训练目标或跨试样阶段识别模型。

数据链：上游 `S1E2_DIC复现和特征分析/cache`、`methodScripts/outputs/frame_index.csv` 与 `Ren2026/outputs/ae_seconds.csv` 共同输入 `01 特征与预处理 → 02 聚类评价 → 03 图表`；`04` 单独分析 DIC 增量场 6 特征。

| 脚本 | 实际工作 | 主要输出 |
| --- | --- | --- |
| `01_features.py` | 构造 20 个 DIC 形态/动态特征；重算 AE 因果剪切撞击计数，形成 14 个 AE 特征；按秒合并、填补、缩放及 PCA | `frame_features_sf.csv`、`samples.csv`、`feature_catalog.csv`、`scaled_*`、`embed_*`、`preprocess.json` |
| `02_cluster_baseline.py` | KMeans / GMM / Ward；k=4 主实验、k=2–8 扫描、随机种子稳定性、特征组消融、时间基线、随机连续分段零模型、前段拟合外推及 E1 对照 | `metrics_main.csv`、`cluster_labels.csv`、`stability.csv`、`metrics_group_ablation.csv`、`extrapolation.csv` 等 |
| `03_visualize.py` | 复用 E1 绘图函数，补充 E1/E2 对照、相对等级空间分布 | 图 1–9，共 10 张 PNG（图 2 分 a/b） |
| `04_incremental_only.py` | 仅用增量场 6 特征重新预处理、聚类；分析 PCA 载荷、阶段统计与理想噪声参照 | `inc6_*`、增量组嵌入及图 10–13 |

现有数据：2300 帧、5 fps；逐秒样本 458 个（0–457 s），其中 447 个用于阶段评价。阶段为“起裂前 / 起裂至损伤 / 损伤至峰值 / 峰后”，边界 270、334、427.3 s；边界不确定样本参与拟合，但不计入 ARI、NMI、轮廓系数和标签匹配。

## 2. 核心代码如何实现

### 2.1 DIC 表征：本轮的主要方法贡献

核心入口为 `01_features.py` 的 `frame_fields()`（113 行）、`shape_stats()`（98 行）、`dic_sf_frames()`（127 行）和 `dic_sf_seconds()`（171 行）。

1. **质量控制与平滑**：读取 `exx/eyy/exy/sigma` 缓存，剔除无效点、`sigma>0.02` 点和边缘，进行 3×3 忽略 NaN 的均值平滑。原始 `sigma<0` 点已在上游缓存构建时剔除。
2. **累积场形态（12 维）**：计算 `γ=√(((εxx−εyy)/2)²+εxy²)`，以当前有效正值的中位数归一化。统计低/高相对等级占比、P98/P50 对数、最高 5% 份额、Gini；另含主应变分布、表观泊松比、成带程度和失配面积。
3. **增量场形态（6 维）**：先将当前帧与 25 帧前的应变分量相减，再计算上述剪应变模长 `Δγ`，仅用两帧均有效的点。**这里的 `Δγ` 是增量张量的剪应变模长，不是 `γ(k)−γ(k−25)`。**
4. **动态量（2 维）**：`acc_log` 比较相邻两个 5 s 增量中位数，实际需要约 10 s 历史；`q98_slope` 为过去 5 个逐秒 `sf_q98` 的线性斜率，单位为 s⁻¹。
5. **逐秒汇总**：将 `[s,s+1)` 内各帧取均值，再做含当前秒的 5 秒尾窗均值；斜率单独计算。用于实时系统时，第 s 行应在该秒采集结束后输出。

| 增量特征 | 代码含义（r=Δγ/median(Δγ)） |
| --- | --- |
| `inc_P2`、`inc_P4` | r≥2、r≥4 的点数占比 |
| `inc_q98` | log₂(P98(Δγ)/P50(Δγ)) |
| `inc_top5` | 最大约 5% 点的 Δγ 总和 / 全部正值 Δγ 总和 |
| `inc_nu` | −median(Δεxx)/median(Δεyy)，截断至 [−1,2] |
| `inc_corr` | 当前累积场与增量场的空间 Pearson 相关：corr(log(γ+10⁻⁹), log(Δγ+10⁻⁹)) |

补充口径：`sf_band` 是高等级区内最大八连通域的点数占比，不是占整个试样的面积；`sf_crack` 以第 1 帧有效内部点为基准统计失配，属于裂缝的代理量。相对分级消除了理想整体倍乘的幅值影响，不等于消除了时间趋势、噪声或加载速率影响；`inc_corr` 的固定小量也使其严格尺度不变性仅为近似。

### 2.2 AE 与通用预处理

`ae_causal_seconds()`（`01_features.py:188`）按时间、记录序号排序，以截至当前撞击的 RA、AF 中位数分别归一化，用 `AF_n<RA_n 且 RA>0` 判剪切；复用 `Ren2026/02_extract_features.py::ae_features()` 形成强度 3、机制 7、动态 3、累积 1 个特征。旧列名 `shear_hits_minmax` 仅用于兼容接口，其内容已替换为因果计数。

`E1_单模态聚类基线/01_features.py::preprocess()`（67 行）实际执行：中位数填补 → 以中位数中心化、`IQR/1.349` 缩放（必要时退回标准差，无法缩放则丢弃）→ 截尾 ±5 → PCA 保留 90% 方差。

### 2.3 聚类与“加载阶段对齐”

`02_cluster_baseline.py::main()` 调用 E1 的 `cluster()`：KMeans 使用 20 次初始化；GMM 为全协方差、5 次初始化、`reg_covar=1e-4`；Ward 为层次聚类。主结果默认 `seed=0`，另对 KMeans/GMM 统计 20 个种子；消融表的 ARI 是 5 个种子的均值，不能与主表视为同一统计口径。

**阶段对齐在聚类之后进行**：E1 的 `align_to_stages()`（53 行）构造簇与参考阶段的列联表，通过匈牙利算法匹配簇号和阶段号。阶段标签和载荷值不进入聚类特征；但 k=4 来自预设阶段数，簇的阶段命名依赖本试样参考标签。ARI 本身不受簇号置换影响，当前没有学得可直接用于新试样的阶段映射。

`contiguous_null()` 随机抽 3 个切点形成 4 个连续段，重复 20000 次；`boundary_offset()` 对每个人工边界寻找**任意最近标签切换点**，并不检查切换前后的阶段语义或持续时间。

## 3. 现有结果复核

下表为保存输出的默认种子结果；DIC 两组 GMM 的 ARI 已由标签独立复算一致。

| 特征集 / 方法 | 聚类维数 | ARI | 零模型百分位 | 全程切换次数 |
| --- | ---: | ---: | ---: | ---: |
| AE 全部 / GMM | 5 | 0.176 | 23.43% | 35 |
| DIC 全部 20 维 / GMM | 4 | 0.502 | 72.97% | 7 |
| DIC 增量动态 8 维 / GMM | 3 | 0.683 | 89.61% | 24 |
| **DIC 增量场 6 维 / GMM** | **1** | **0.718** | **91.75%** | **7** |
| 仅时间 / KMeans | 1 | 0.385 | 53.58% | 3 |

- **增量场 6 维是当前更有价值的 DIC 候选表征**：PC1 解释约 94.3% 方差，主要反映集中程度；绘图另取的 PC2 不参与聚类。20 个种子下 GMM 的 ARI 均为 0.718；DIC 全部特征的 GMM 则为 0.413±0.064，0.502 是默认种子值。
- 全部 DIC 的 GMM 切换时刻为 `159,273,276,277,278,280,362 s`；增量组为 `36,39,302,353,363,377,402 s`。增量组最近边界偏差为 `+32,+19,−25.3 s`，仍不是连续、单向的四阶段序列。
- 增量组峰后 28 个确定样本全部进入“峰后”匹配簇，但该簇也含 37 个“损伤至峰值”样本。因此 README 的“峰后 100% 正确”仅指该阶段样本召回，不能解释为峰值边界准确或峰后簇纯度 100%。
- 零模型 ARI 的 95% 分位为 0.783；增量组仍未超过该阈值。其 91.75% 是相对于指定随机分段方案的经验百分位，不是识别准确率。

依据：`outputs/metrics_main.csv`、`inc6_metrics.csv`、`stability.csv`、`inc6_stability.csv`、`inc6_contingency_GMM.csv`、`null_model.csv`、`run_04.log`。

## 4. 对研究结论与后续代码的约束

1. **“全部因果”需要限定范围。** 本轮取消了峰前参考带和全程幅值归一化，但主实验的填补、缩放、PCA、聚类仍使用全程样本；上游 DIC 时间偏移 −0.72 s 也由后期载荷与位移变化离线估计。README 的“只用当前帧和 5 s 前帧”未覆盖 `acc_log`、初始失配基准和逐秒平滑。当前应表述为“局部特征采用历史窗口，整体为离线评价”。
2. **外推实验不等于新状态发现实验。** `02` 用 `sec<T` 拟合预处理与固定 4 分量 GMM；T=300 时 DIC 全程 ARI 为 0.073。`new_cluster_share_unseen=0` 只表示未预测到训练段未占用的分量，模型本身没有增加新状态的机制；表中也没有单独报告留出段 ARI。
3. **物理解释应与实现结果区分。** 约 159 s 对应“压密结束”、噪声主导早期增量等属于待独立验证的解释。`noise_reference()` 是理想 Rayleigh 噪声模拟，并非实测噪声标定；`inc_nu>0.5` 的扩容解释也需要相应力学假设。
4. **复用时注意缓存与数值边界。** `01` 发现 `frame_features_sf.csv` 即直接复用，没有参数/源码版本校验；修改窗口或公式后需显式更新缓存。`shape_stats()` 未处理空正值集合，泊松比分母未设噪声阈值；迁移数据时应补充有效点数、近零分母和非有限值检查。`02` 注释中的 `boundary_offset.csv` 未实际生成，偏差保存在指标表中。
5. **面向项目总目标的下一步**：以增量场 PC1 为 DIC 候选主分量，结合 AE 强度、突发性及少量有独立依据的辅助量开展融合消融；在训练试样上固定预处理和阶段映射，在留出试样验证阶段与边界。在线识别还需独立校时、历史拟合/更新机制，以及明确的状态持续性或新状态检测规则。

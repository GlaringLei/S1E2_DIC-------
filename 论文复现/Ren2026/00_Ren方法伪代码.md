# Ren et al. (2026) 方法伪代码：DIC 局部化特征与 AE 特征

> Ren H, Luo H, Pan Y, et al. Correlations between strain localisation evolution and acoustic emission characteristics of granite subjected to uniaxial compression. *JRMGE*, 2026, doi:10.1016/j.jrmge.2025.11.043.

**这篇论文的思路**：用 DIC 找到试样表面的"局部化带"（将来破裂的位置），盯住带两侧的相对运动，判断局部化什么时候开始、什么时候加速。再对照同一时刻的 AE 事件率、拉伸/剪切事件比例和 AE 平静期，说明两者的对应关系。

每一步先写原文做法，再写本项目在 HS-2 上的实现，以及代码位置。

---

## 0. 输入

```
DIC：每帧 k 有一张点场，每个测点 i 有
      参考坐标 (x_i, y_i)、位移 (u_i, v_i)、应变 (exx_i, eyy_i, exy_i)
      帧时间 t_k（HS-2：平均 5 帧/秒）
AE ：每条撞击记录 h 有
      到达时间 t_h、幅度 A_h、上升时间 RT_h、持续时间 D_h、振铃计数 N_h、能量 E_h
载荷：仅用于事后对照，不作为特征
```

HS-2 的对齐方式（不做强对齐）：
- AE 与载荷：使用 `AE-载荷.xlsx` 已对齐的时间，阶段取自 `AE阶段参考标注明细.csv`。
- DIC：t = t0 + 帧号/5，t0 = −0.72 s（`methodScripts/01`）。
- 所有量统一放到"逐秒格"上：第 s 秒格包含 AE 时间为 s 的撞击，以及 t ∈ [s, s+1) 的 DIC 帧。

## 1. DIC：从应变场得到最大剪应变场

```
for 每一帧 k:
    for 每个测点 i:
        γmax[k, i] = sqrt( ((exx - eyy)/2)^2 + exy^2 )     # = (ε1 - ε2)/2，原文式 (3)(4)
```

- 原文先由位移场求 Green–Lagrange 应变，再求主应变。Vic-2D 已经直接给出应变，这里直接使用。
- 数据中的 `gamma` 列是主方向角（±π/2），不是剪应变，不能代替 γmax。
- 代码：`methodScripts/02_frame_features.py: gamma_max()`

## 2. DIC：找到局部化带

```
原文：在应力–应变曲线上取一个"带已经清楚"的时刻 d，人工在 γmax 图上圈出局部化带，
      量出带的位置、走向（与加载方向的夹角 α）和宽度。

本项目（自动、可复现）：
    选参考帧 = 峰值前 5 s 的那一帧
    掩膜 = { γmax 平滑后 > 中位数 + 3 × 四分位距 } ∪ { 失配/裂缝点 }
    主带 = 掩膜中最大的连通区域里，每行只有一段连续占据的那一段
    中心线 = 主带每一行的中点连线
```

- 代码：`methodScripts/02_frame_features.py: band_mask(), build_reference()`
- 结果：`methodScripts/outputs/fig_band_reference.png`、`band_reference.json`

## 3. DIC：带两侧的相对张拉与相对滑移

```
在中心线的 25% / 50% / 75% 处各取一个断面 j：
    t_j = 局部走向（沿带的单位向量），n_j = 法向（垂直于带）
    在带两侧各放一个小方窗：
        原文 5×5 像素，窗心离带边界 10 像素
        HS-2 换算为 3×3 网格点，窗心离带边界 5 个网格点（≈1.9 mm）
    监测窗固定在参考坐标上（物质点），所有帧都用同一组窗

for 每一帧 k，每个断面 j:
    d_右 = 右窗内 (u, v) 的中位数；d_左 = 左窗内 (u, v) 的中位数
    Δ = d_右 − d_左
    【本项目补充】Δ_net = Δ − (整帧均匀变形在两窗间产生的位移差)
        # 两窗相距约 10 mm，均匀应变本身就会贡献几十 μm，必须扣掉
    相对张拉 δn[k, j] = Δ_net · n_j      # 正值 = 张开
    相对滑移 δs[k, j] = Δ_net · t_j      # 沿带的错动
```

- 代码：`methodScripts/02_frame_features.py: frame_features()`，输出列 `dn_net_j`、`ds_net_j`

## 4. DIC：速率，以及"起始 / 缓慢 / 加速"的判别

```
原文：速率 = |δ(k) − δ(k−1)| / 帧间隔
本项目：逐帧差分噪声太大（信噪比 < 1.2），改为 5 s 窗口内线性拟合的斜率
    δ̇n[k, j], δ̇s[k, j]，单位 μm/s
    合位移 |δ|[k] = 三个断面 sqrt(δn² + δs²) 的平均，其速率记为 |δ̇|

局部化起始 t_ini（原文：带内外开始出现位移不连续）：
    基线 = 加载初期（5–60 s）速率的均值 μ、标准差 σ
    t_ini = 至少 2 个断面的速率持续 ≥ 5 s 超过 μ + 5σ 的最早时刻

缓慢演化：t_ini 之后，相对位移增长很小
加速演化（原文：张拉、滑移速率陡增，各断面接近）：
    r0 = t_ini 到峰值之间 |δ̇| 的中位数，MAD 为其离散程度
    加速区间 = |δ̇| > r0 + 5 × MAD 且持续 ≥ 1 s 的时段
断面同步性 = 三个断面速率的变异系数（原文：加速时接近，平静期内不同步）
```

- 代码：`methodScripts/03_window_analysis.py: window_slope(), ren_events()`
- HS-2 结果：加速区间稳定在 368–372 s、403–407 s、429–435 s。t_ini 随窗长和阈值在 210–362 s 之间漂移，不能作为稳定的边界。

## 5. DIC：围岩应变能与带上剪应力

```
在中段断面外侧 30 像素处取 15×15 像素区域（HS-2：带外 15 个网格点处取 7×7 网格点）
平面应力：
    σx = E/(1−ν²)·(εx + ν·εy)，σy = E/(1−ν²)·(εy + ν·εx)，τxy = E/(1+ν)·εxy
    σ1, σ2 = 主应力
围岩应变能密度 U = (σ1² + σ2² − 2ν·σ1·σ2) / (2E)          # 原文式 (5)
带上剪应力   τα = ½(σx − σy)·sin2α + τxy·cos2α             # 原文式 (6)
```

- HS-2 缺少 E、ν，取 E = 1、ν = 0.25。只看曲线形状和峰值时刻，不看绝对值。
- 代码：`论文复现/Ren2026/01_build_series.py: energy_shear()`（3 个断面）

## 6. AE：事件率与拉伸/剪切分类

```
for 每条撞击 h:
    RA_h = RT_h / A_h               # 上升时间 / 幅度，ms/V
    AF_h = N_h / D_h                # 振铃计数 / 持续时间，kHz
    原文：RA、AF 先归一化，以 AF/RA = 1 为界：
        AF/RA > 1 → 拉伸型；AF/RA < 1 → 剪切型
    （原文没写归一化方式。本项目用 min-max 作主口径，P1–P99 截尾和中位数归一作对照）

for 每一秒 s:
    AE 率          = 该秒撞击数（HS-2 为 4 个通道的撞击合计，不是定位事件）
    拉伸率 / 剪切率 = 该秒拉伸型 / 剪切型撞击数
    剪切占比        = 剪切数 / 总数（用 5 s 滑动和计算，避免分母为 0）
原文还把全程分成六段，统计每段的剪切占比（18% → 35% → 41%）
```

- 代码：`论文复现/Ren2026/01_build_series.py: ae_seconds()`

## 7. AE：平静期

```
原文：根据振铃计数和累计事件率曲线人工识别，即累计曲线明显变平的一段。
本项目：
    规则 A：活跃期（前 30 s 平均 ≥ 10 次/s）内，逐秒撞击数连续为 0 且 ≥ 5 s
    规则 B：5 s 平均撞击率 < 前 30 s 中位数的 20%，且持续 ≥ 5 s
```

- HS-2 识别到 357–365 s。但 356 s 一秒集中了 1128 次撞击，约等于 8 s 的正常量，**很可能是采集缓存批量写盘造成的空档**，不是真正的平静。
- 代码：`01_build_series.py: quiet_periods()`；诊断见 `04_check_ren_conclusions.py`

## 8. 原文的联合分析（本项目用来做核对）

```
1. 局部化起始 t_ini 前后：AE 率是否骤降
2. 加速区间内：AE 率是否激增，剪切占比是否升高
3. AE 平静期内：δn、δs 是否仍在增长，末段是否开始加速
4. 围岩 U 的峰值是否接近 AE 率峰值；平静期后 τα 是否陡降
```

- 代码：`04_check_ren_conclusions.py`

## 9. 由此导出的逐秒特征（交给 02、03）

每 1 s 输出一个样本，用**过去 W 秒（W = 5，敏感性对照 W = 10）**的数据计算，只用过去、不用未来。

| 模态 | 特征 | 来源 | 类型 |
| --- | --- | --- | --- |
| AE | 撞击率、振铃率、能量率（取对数） | Ren §6 | 强度 |
| AE | 拉伸率、剪切率、剪切占比 | Ren §6 | 机制 |
| AE | RA、AF、幅度、持续时间的窗口中位数 | Ren §6 | 波形 |
| AE | 零计数秒占比（平静程度）、撞击率斜率 | Ren §7 | 动态 |
| AE | 累计撞击数（取对数） | Ren §7 | 累积/趋势 |
| DIC | 相对张拉 δn、相对滑移 δs、合位移 \|δ\| | Ren §3 | 累积/趋势 |
| DIC | δ̇n、δ̇s、\|δ̇\|、相对加速比（\|δ̇\| / 前 30 s 中位数） | Ren §4 | 动态 |
| DIC | 断面速率变异系数（不同步程度） | Ren §4 | 动态 |
| DIC | 围岩 U、带上 τα 及其变化率 | Ren §5 | 状态 / 动态 |

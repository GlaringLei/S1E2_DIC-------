# E3 阶段聚合变换与应变集中特征：让 DIC 样本"阶段内聚合、阶段间离散"，并评估 Dong 应变集中特征（HS-2）

**本轮要回答的两个问题**
1. 能否在 E2 的 DIC 尺度无关表征上，再做一种**同样与尺度无关、且不使用标签**的变换，使样本在特征空间里阶段内聚得更紧、阶段间分得更开？
2. Dong et al. (2024) 的应变集中计算模型（SCCM，按固定量程统计应变集中区的面积占比）有没有参考价值？把它纳入表征是否可行？

研究目标、评价方式和目录结构与 [E1](../E1_单模态聚类基线/README.md)、[E2](../E2_尺度无关DIC特征聚类/README.md) 保持一致：
- 聚类：GMM / Ward，k = 4；
- 评价：ARI 为主；轮廓系数为辅，另报 Fisher 比；
- 固定附带：零模型百分位（随机切 4 个连续时间段，95% 分位 ARI = 0.78）、边界偏差、特征与时间的 |ρ|。

**运行**：需先跑完 `../E2_尺度无关DIC特征聚类/01–02`。

```
python 03_visualize.py       # 图 3–8                                                约 15 s
```

## 1. 方法

### 1.1 起点：E2 的问题在哪里
E2 中只用增量场 6 个特征（`inc_P2`、`inc_P4`、`inc_q98`、`inc_top5`、`inc_nu`、`inc_corr`）时 ARI 为 0.72。但鲁棒标准化后做 PCA，第一主成分占了 94%，6 个特征实际上被压成了**1 维**。原因是：
- 4 个"集中度"特征（A 组）高度共线，在 PCA 中占了 4 份权重；
- `inc_nu`（增量泊松比）和 `inc_corr`（增量场与累积场的空间相关）表达的是另外两种物理量，却各只占 1 份，被压在了 4% 的第二主成分里。

所以，"阶段内聚合、阶段间离散"不好，未必是特征不行，而可能是**各个物理量在变换中的权重分配不合理**。

### 1.2 本轮比较的变换（全部不使用标签、与尺度无关）

| 编号 | 变换 | 做法 | 想解决什么 |
| --- | --- | --- | --- |
| T0 | E2 基线 | 增量场 6 个 → 全序列鲁棒 z → PCA 90% | 对照 |
| T1 | 噪声锚定 log-SNR | 每个集中度特征除以"纯噪声时的理论值"再取对数，例如 log(`inc_P2` / 0.0625)；`inc_nu`、`inc_corr` 原样 | 不使用任何数据统计量，跨试样无需重新标定；对数压缩后期的大值 |
| T2 | 基线锚定 | 以加载初期 10–60 s（应变增量 ≈ DIC 噪声）为参照做标准化 | 因果，只用最早一段数据 |
| T3 | 因果平滑 | 对每列做过去 10 s / 30 s 的滚动中位数 | 压缩阶段内的逐秒波动 |
| **T4** | **分块 MFA** | 按物理含义把特征分块；每块鲁棒 z 后**除以本块第一奇异值**（每块对总方差的贡献相同），再拼接 → PCA 90% | 共线特征不再"多数压制少数"，每种物理量同权 |
| T5 | 直接拼接 | 增量场 6 个 + Dong 固定量程 5 个，不分块 | 对照：Dong 特征直接加入 |
| T6 | 慢特征分析 SFA | 在增量场 6 个 + 累积形态 5 个上，提取随时间变化最慢的 3 个方向 | 阶段是"慢变量"，逐秒波动是"快变量" |
| REF | 有监督 LDA | 用标签，阶段分层的分块交叉验证 | 只作参照，不参与比较 |

T4 的分块（每块对应一种物理量）：
- **A 增量集中**：`inc_P2`、`inc_P4`、`inc_q98`、`inc_top5`，即"新增变形有多集中"；
- **B 增量运动学**：`inc_nu`（侧胀 / 扩容）、`inc_corr`（是否沿已有集中带发展）；3 块版本中再拆成两块；
- **C 累积形态**：`sf_tens`、`sf_nu`、`sf_e2low`、`sf_P4`、`sf_crack`（来自 E2）；
- **D Dong 固定量程**：见 §1.3。

### 1.3 Dong SCCM 原文特征（固定量程）
按原文做法，但改为直接对数值场统计（`01_features.py`）：
- ε1 在 [0, 30‰] 内均分 32 级，ε2 在 [−10‰, 0] 内均分 32 级，逐帧统计每级的面积占比；
- 逐秒特征（过去 5 s 平均）：
  - `dong_P1_ge3`：P(ε1 ≥ 2.81‰)；
  - `dong_P1_ge6`：P(ε1 ≥ 6.56‰)，接近 Dong 6 件试样的微损伤临界应变 εmd（5.4–6.7‰）；
  - `dong_P1_ge12`：P(ε1 ≥ 12.2‰)；
  - `dong_P2_init`：ε2 初始等级（−0.31‰–0）占比，对应 Dong 判据 2，反映压密；
  - `dong_level_entropy`：ε1 在 32 级上分布的归一化熵。
- 两个判据的事件时刻：
  - **判据 1**：P(ε1 ≥ θ) 首次 ≥ 2% 的时刻，扫描 θ = 1.9–12.2‰；
  - **判据 2**：ε2 初始等级占比的最低点，以及首次低于 2% 的时刻。

**最佳无监督变换**为 T4 三块 MFA [A | inc_nu | inc_corr]（图 4，GMM）。列联表：

### 2.2 解读：什么样的变换能让阶段"内聚、外离"

**(1) 关键在于"按物理量分块等权"（MFA），不是对数变换或平滑。**
- 只在 1 维上做变换（T1–T3），ARI 都停在约 0.72。对数或噪声锚定能让 Fisher 比变大（10 → 15–17），但这是把起裂前压缩得更紧造成的（图 3 上排），阶段的排序和边界位置都没变。
- 时间平滑（T3）反而降低轮廓系数（0.45 → 0.30）：阶段边界附近的样本被抹到相邻阶段，阶段间距离缩小得更多。
- 分块 MFA 让 `inc_nu`、`inc_corr` 的权重从 4% 提升到与集中度相当（第二主成分占 19%），样本空间从"一条线"变成"一条弯曲的轨迹"（图 3、图 4）：
  - 起裂前：左下的紧密团；
  - 起裂至损伤：轨迹的"拐弯"处。`inc_nu` 先超过 0.5（扩容开始），集中度才开始上升，所以这一段在 C2 方向上被抬起，与起裂前分开；
  - 损伤至峰值：沿 C1 向右拉开；
  - 峰后：`inc_nu` 由正转负（侧胀停止、以滑移为主），在 C2 上明显下沉，与损伤至峰值分开。
- 结果：人工阶段轮廓系数 0.45 → 0.57，"阶段内半径 / 最近中心距"0.90 → 0.45，ARI 0.72 → 0.90，零模型 92% → 99.3%。这是本项目到目前为止**第一个在零模型下显著（p < 0.01）的无监督 DIC 表征**。

**(2) Fisher 比和轮廓系数给出的结论不一致，选变换应以轮廓系数和 ARI 为准。**
- Fisher 比是"阶段间散度 / 阶段内散度"，会被一个很大、很紧的阶段（起裂前 269 个样本）主导。T2 把起裂前压得极紧，Fisher 比最高（17.1），但相邻阶段之间并没有分得更开，轮廓系数反而下降。
- 轮廓系数和"阶段内半径 / 最近中心距"直接衡量**最难分的相邻两个阶段**，更符合"阶段间离散"的要求。

**(3) 再加入更多的块会降低效果。**
- 加入累积形态块 C 后，GMM 降到 0.36，Ward 仍为 0.85。
- 加入 Dong 块 D 后，ARI 降到 0.41–0.51。
- 原因是 C、D 两块中的主要变化发生在**起裂前内部**：140–170 s 的压密结束（ε2 初始等级占比骤降，见 §2.3）。按 MFA 等权后，这一段阶段内变化与阶段间变化同等重要，起裂前被拆成两簇（图 5 中 T4 [A|B|D] 把 0–100 s 判成了单独一簇）。

**(4) SFA 和有监督 LDA 都不好，说明这里的"阶段"不是全局线性可分的。**
- SFA 找的是"变化最慢"的方向，而单调加载中变化最慢的方向往往就是时间，与时间相关反而低的方向又不对应阶段。
- LDA 在分块交叉验证下只有 0.64。每折测试的是各阶段内一段"没见过的时间"，阶段内特征有漂移，线性投影外推不了。这说明它不是真正的"上限"，同时也说明**阶段是轨迹上的区段，不是线性可分的团块**，分块 MFA + GMM 这种"先展开轨迹、再按局部密度切分"的做法更合适。

### 2.3 Dong 应变集中特征（图 7、图 8，`dong_feature_eval.csv`、`dong_events.json`）

**(1) 单个特征的阶段区分度很高，但几乎都是时钟。**

| 特征 | 与阶段 ε² | 与时间 \|ρ\| | 各阶段中位数（起裂前 / 起裂至损伤 / 损伤至峰值 / 峰后） |
| --- | --- | --- | --- |
| `dong_P1_ge12` P(ε1 ≥ 12.2‰) | **0.95** | 0.88 | 0.000 / 0.006 / 0.161 / 0.379 |
| `dong_P1_ge6` P(ε1 ≥ 6.56‰) | 0.87 | 0.95 | 0.000 / 0.047 / 0.328 / 0.540 |
| `dong_P1_ge3` P(ε1 ≥ 2.81‰) | 0.78 | **0.99** | 0.003 / 0.379 / 0.612 / 0.788 |
| `dong_level_entropy` | 0.77 | **1.00** | 0.07 / 0.56 / 0.80 / 0.88 |
| `dong_P2_init` | 0.60 | 0.81 | 0.069 / 0.000 / 0.000 / 0.008 |
| *对照：`inc_corr`（增量场）* | 0.76 | 0.86 | |
| *对照：`inc_P4`（增量场）* | 0.70 | 0.67 | |

- ε² 高达 0.95，说明在单试样上，Dong 特征单独看就能很好地"排序"阶段，三个相邻阶段的区分度大多为 1.00（图 8b）。
- 但这正是 E1 §7.3 指出的问题：**固定量程下，各等级的占比随应变幅值单调上升**。它们与时间的 |ρ| 为 0.88–1.00，本质上是"整体应变已经多大"的读数，与 E1 的幅值特征同类，属于需要剔除的尺度效应。
- 因此放进无监督聚类后效果反而差：仅 Dong 特征 ARI 0.35，轮廓系数 0.01；与增量场直接拼接后 0.44。高 ε² 来自单调排序，而单调量在聚类中形成的是一条均匀的长带，没有密度低谷可切，切在哪里主要取决于样本数分布。

**(2) Dong 判据 1（εmd）的事件时刻完全由所选阈值决定**（图 7b）。
- P(ε1 ≥ θ) 首次达到 2% 的时刻随阈值几乎线性后移：θ = 1.9‰ → 153 s，3.8‰ → 218 s，6.6‰ → 274 s，9.4‰ → 306 s，12.2‰ → 328 s。
- 如果套用 Dong 原文的 εmd（5.4–6.7‰），得到 258–274 s，碰巧接近人工起裂边界（270 s）。但原文的 εmd 来自**含预制缺陷的红砂岩**，直接迁移到花岗岩没有依据；在 HS-2 上，阈值每变化 1‰，事件时刻就移动约 15–25 s。
- 因此，在没有独立标定 εmd 的情况下，**判据 1 不能作为可靠的阶段边界**。

**(3) Dong 判据 2（压密结束）在 HS-2 上有效，且与 E2 的发现一致。**
- ε2 初始等级占比在 60–150 s 从约 95% 降到 0，**首次低于 2% 的时刻为 152 s**（图 7c）。
- 这与 E2 中 DIC-SF 聚类在约 159 s 的切分、`sf_e2low` 骤降（155 s）相互印证，对应 Dong 所说的"压密结束"。
- 原文用的是"占比最低点"，但 HS-2 上该占比降到 0 后会一直保持，最低点没有确定意义（argmin 落在 237 s），所以改用"首次 < 2%"。
- 人工阶段没有"压密"这一档，所以这一事件在 ARI 中无法得到认可，反而会把起裂前拆开、拉低 ARI（§2.2 (3)）。

## 3. 结论

1. **能做到。** 在不使用标签、不引入尺度量的前提下，对 E2 增量场特征做**按物理量分块的 MFA**（集中度 | 增量泊松比 | 增量-累积相关，每块等权），就能明显改善"阶段内聚合、阶段间离散"：
   - 人工阶段轮廓系数 0.45 → **0.57**，阶段内半径 / 最近中心距 0.90 → **0.45**；
   - ARI 0.72 → **0.90**，超过 99.3% 的随机连续分段，起裂边界偏差为 0 s。

   起作用的是让被共线集中度特征压制的两个运动学量（`inc_nu`、`inc_corr`）恢复同等权重。对数、噪声锚定、时间平滑都不能改变阶段的相对结构。
2. **Dong 应变集中特征有参考价值，但不宜直接纳入表征。**
   - **可借鉴的**：一是"按等级统计面积占比"的思路，E2 的相对分级就是由此改造而来；二是**判据 2**（ε2 初始等级占比 → 压密结束），在 HS-2 上于 152 s 给出了与 DIC-SF 聚类一致的物理事件，可作为"起裂前内部压密 / 弹性"细分的独立依据。
   - **不宜纳入的**：固定量程的占比特征与时间相关 0.88–1.00，属于幅值量；判据 1 的事件时刻随阈值线性漂移，阈值无法从本试样独立确定。纳入后 ARI 从 0.87 降到 0.41–0.51。
   - **可行的用法**：把判据 2 的事件作为**辅助的事件型指标**，例如单独输出"是否已完成压密"的二值量或时刻，不作为连续特征参与聚类；或者在今后有独立力学依据把起裂前细分时，用它来检验 DIC 的压密切分。
3. **对后续融合的启示**：
   - DIC 端建议固定使用 T4 三块 MFA 表征（2 维）；
   - 与 AE 融合时延续"按物理量分块等权"的做法，AE 也按强度 / 机制 / 动态分块，不要直接拼接；
   - 识别器优先用能沿轨迹按密度切分的方法（GMM、带时序约束的方法）。

## 4. 局限
- **方法选择存在事后挑选**：T4 三块版本是在看到两块版本的结果之后加的，"最佳"变换是在 14 种中按 ARI 挑出的。分块依据是物理含义，不是调参；但它在新试样上能否同样最优，需要多试样验证。
- **只有一个试样**。分块 MFA 中"每块除以第一奇异值"用到了全序列统计量，在线使用时需改为用训练试样或早期数据估计。
- Dong 原文用的是含缺陷红砂岩、Vic-2D 云图颜色分级；这里是完整花岗岩、数值分级，量程沿用原文（ε1 0–30‰、ε2 −10–0‰），未针对花岗岩重新标定。
- 人工阶段没有"压密"一档，Dong 判据 2 与 DIC 的压密切分无法在 ARI 中被评价。
